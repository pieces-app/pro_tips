# How to Apply a Discount Code at Checkout for Pieces Pro or Enterprise

## Overview

Whether you're upgrading to **Pieces Pro** or **Pieces Enterprise**, applying a discount code at checkout is quick and straightforward. This guide walks you through the exact steps to make sure your discount is applied before you complete your purchase.

## Before You Start

Make sure you have:

- A valid **discount code** (provided via a promotion, partner offer, or your organization)
- A **Pieces account** — you'll need to be signed in to reach checkout
- A decision on your plan: **Pieces Pro** (individual) or **Pieces Enterprise** (team/organization)

---

## Step-by-Step: Applying a Discount Code

### Step 1 — Click Upgrade from Within the App

From anywhere inside the Pieces Desktop App, click the **Upgrade** button. This will open the Pieces checkout page in your default web browser — you don't need to navigate to a separate website or find a hidden settings page.

### Step 2 — Enter Your Personal Information

Once the checkout page loads in your browser, you'll be asked to provide a few personal details. Fill in the required fields to continue to the payment screen.

### Step 3 — Find the Discount Code Field

On the checkout screen, look for the small **green "Add discount"** text located **above the credit card fields**. It's easy to miss — it's intentionally subtle. Click on it to reveal the discount code input field.

### Step 4 — Enter and Apply Your Discount Code

Type your discount code into the field and submit it. If the code is valid, the discount will be applied immediately — you'll see the **totals update to reflect the new discounted price**. Double-check that the updated amount matches what you expect before proceeding.

### Step 5 — Complete Your Purchase

With the discount confirmed and reflected in your total, fill in your payment details and complete the checkout. Once the purchase is finalized, your plan will reflect the applied discount.

## Troubleshooting

### Discount Code Not Working?
- **Check for typos** — Discount codes are usually case-sensitive. Double-check that you've entered it exactly as provided
- **Verify expiration** — Some codes have an expiration date. Confirm your code is still valid
- **Plan eligibility** — Certain codes may only apply to Pieces Pro or Pieces Enterprise, not both. Make sure the code matches the plan you're purchasing

### Discount Not Reflected in Total?
- Make sure you clicked **Apply** after entering the code — it won't auto-apply
- If the discount still doesn't appear, try refreshing the page and re-entering the code
- Contact [Pieces Support](https://pieces.app) if the issue persists

### Already Subscribed and Have a Code?
- If you're already on a paid plan and received a discount code, reach out to [Pieces Support](https://pieces.app) to have it applied to your existing subscription

## Pro Tips

### 1. Apply Before You Pay
Always enter your discount code **before** completing payment. Most codes cannot be applied retroactively.

### 2. Share with Your Team
If your organization received a discount code for Pieces Enterprise, make sure the person handling billing has the code before they start the checkout process.

### 3. Stack-Friendly?
Some promotions may be combinable. If you have multiple codes, try applying each one to see if they stack — but most checkouts accept one code at a time.
